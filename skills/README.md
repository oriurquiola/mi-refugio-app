# skills/ — Procedimientos reutilizables

Convertir tareas repetitivas en pasos fijos, para no re-derivarlas cada sesión.

## Routing
| Necesito… | Skill |
| --- | --- |
| Levantar la app y ver un cambio en vivo | `run-dev.md` |
| Verificar un cambio en el navegador | `run-dev.md` §Verificación |
| Cerrar sesión: guardar estado/decisiones/log | `end-session.md` |

Al detectar un procedimiento nuevo que repites ≥ 2 veces, créalo aquí como `slug.md` (pasos numerados, denso).
