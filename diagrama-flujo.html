3. Flujo de datos de ejemplo

data.ts → symptoms[]

→
Symptoms.tsx

→
App.tsx (estado)
onContinue(ids) guarda selectedSymptoms en el estado global y navega
→
Recommendations.tsx
Recibe selectedSymptoms como prop → filtra symptoms[] para mostrar las etiquetas "detectadas"
data.ts → techniques[]
3 técnicas fijas (Respiración 4-7-8, Grounding 5-4-3-2-1, Ancla de seguridad) con pasos
→
Recommendations.tsx
Muestra todas las técnicas — el código las asigna estáticamente ("MVP: no hay mapeo real síntoma→técnica" según comentario en Recommendations.tsx:16)
→
data.ts → mockHistory[]
2 sesiones de ejemplo (Hoy / Ayer) — definidas pero no consumidas por ninguna pantalla actual
